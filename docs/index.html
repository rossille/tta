What you're getting into

2–4 player LAN

Auto-discovery on the local network. Same room, same Wi-Fi, same chaos. No accounts, no menus to navigate, no servers to wrangle.

AI grunts

Three difficulty tiers with navmesh pathfinding and line-of-sight aiming. Fill any empty seat and the bots will gladly try to kill you.

Tanks start dry

Zero rounds in the breech. The whole match is a scramble for ammo crates — nobody hides in a corner waiting it out.

Ramming is a strategy

Out of bullets? Pick up speed and bury your nose in someone's armor. Damage scales with closing speed.

Built to feel mean

Tank weight in the controls. Tread marks in the sand. Muzzle flash, hit flashes, debris, screen shake, lingering wreck fires. The little details that turn a prototype into a thing you actually want to play.

macOS one-liner recommended

macOS Sequoia blocks unsigned apps with a dead-end "Done" button. Skip the dance — paste this into Terminal.app. It downloads the latest build, installs to ~/Applications, strips the quarantine flag, and launches the game. 

curl -fL -o /tmp/TankArena.dmg https://github.com/rossille/tta/releases/latest/download/TankArena.dmg && hdiutil attach -nobrowse -quiet /tmp/TankArena.dmg && mkdir -p ~/Applications && rm -rf ~/Applications/TankArena.app && cp -R /Volumes/TankArena/TankArena.app ~/Applications/ && hdiutil detach -quiet /Volumes/TankArena && rm /tmp/TankArena.dmg && xattr -dr com.apple.quarantine ~/Applications/TankArena.app && open ~/Applications/TankArena.app

After the first run, launch the game any time with ⌘Space → TankArena or from Launchpad.

Already downloaded the .dmg?  Or prefer the GUI?

If the .dmg is in your Downloads, skip the re-download:

hdiutil attach -nobrowse -quiet ~/Downloads/TankArena.dmg && mkdir -p ~/Applications && rm -rf ~/Applications/TankArena.app && cp -R /Volumes/TankArena/TankArena.app ~/Applications/ && hdiutil detach -quiet /Volumes/TankArena && xattr -dr com.apple.quarantine ~/Applications/TankArena.app && open ~/Applications/TankArena.app

GUI fallback (no Terminal):

  1. Download the .dmg above and drag TankArena.app into /Applications.
  2. Double-click it — you'll see "Apple could not verify TankArena…". Click Done.
  3. Open System Settings → Privacy & Security. Scroll to Security and click Open Anyway.
  4. Authenticate with Touch ID, then double-click the app again. It will launch.
